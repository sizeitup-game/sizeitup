# Size trivia: 40 questions with answers

How big are things, really? These questions come from the objects in [SizeItUp](https://sizeitup.us/), the free daily size comparison game. Every number is from the game's sourced data, and every answer links to the object's page on SizeItUp and to the source behind its size.

Try answering before you open each one. Then [play today's puzzles](https://sizeitup.us/) and guess sizes by eye.
